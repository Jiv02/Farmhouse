# 🏡 Farmhouse Landing Page  

A beautiful, responsive landing page for a countryside retreat, built with **HTML, CSS, and Tailwind CSS**. Perfect for showcasing a serene farmhouse getaway with a clean, modern design.  

**Live Demo:** [https://beautiful-fudge-599537.netlify.app/](https://beautiful-fudge-599537.netlify.app/)  

---

## ✨ Features  
- **Responsive Design**: Flawless display on mobile, tablet, and desktop.  
- **Modern UI**: Elegant layout powered by Tailwind CSS.  
- **Interactive Elements**:  
  - Smooth scrolling navigation.  
  - "Inquiry Now" button (links to contact form).  
  - Hover effects on buttons and images.  
- **Key Sections**:  
  - 🌄 Hero section with a compelling call-to-action.  
  - 📖 About section (image + description).  
  - 🖼️ Gallery section.  
  - ✉️ Contact form.  

---

## 🛠️ Technologies Used  
- **HTML5**  
- **CSS3** (with Tailwind CSS)  
- **Tailwind CSS** (Utility-first framework for rapid styling)
